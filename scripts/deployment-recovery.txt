Codex Lite: 手動で旧版に戻す方法

デスクトップに現在使用中と退避2世代の合計最大3世代を保持します。
  Codex Lite            現在使用中。ショートカットは常にここを参照します。
  Codex Lite-previous   前回まで使用していた一式。
  Codex Lite-previous2  さらに一つ前の一式。

保存はこの方式でのデプロイから蓄積します。最初から3世代は揃いません。
各フォルダーの deployment-info.json に準備時刻(UTC)とクライアントの
バージョン・SHA256を記録します。以前の方式で作った版にはこのファイルが
ない場合があります。daemon/、remote-agent/、cloud-sync.jsonも世代ごとに残ります。

前回の版に切り替える手順（Codex Lite自体が起動できなくても実行可能）
1. Codex Liteを終了します。関連デーモンの終了まで待ちます。
   フォルダー名を変更できない場合は中止し、関連プロセスの終了を確認してください。
2. エクスプローラーでデスクトップを開きます。
3. Codex Lite-swap が存在しないことを確認します。既存のものを上書きしないでください。
4. フォルダー名を次の順で変更します。
     Codex Lite          → Codex Lite-swap
     Codex Lite-previous → Codex Lite
     Codex Lite-swap     → Codex Lite-previous
5. いつものCodex Liteショートカットで起動します。

2世代前に戻す場合は、手順4の Codex Lite-previous を
Codex Lite-previous2 に読み替えてください。同じ手順で元の版にも戻せます。
デプロイ失敗で Codex Lite が存在しない場合は、起動する退避フォルダーだけを
Codex Lite に名前変更してください。Codex Lite-next は準備中のため使わないでください。

注意
・退避フォルダー内のEXEを直接起動せず、名前を入れ替えてから起動してください。
・アプリを実行中のまま入れ替えたり、複数の版を同時起動したりしないでください。
・これはプログラム一式の切り替えです。WSLの会話DB、履歴、設定、Codex本体は
  共通であり、巻き戻しません。古いアプリが新しいDB形式に対応できない場合は
  起動できません。DBファイルを削除して対処しないでください。
・同期設定は選んだ世代のcloud-sync.jsonになります。設定を世代間でコピーする
  場合はファイルとして扱い、内容をログや会話へ貼らないでください。
・次のデプロイでは現在使用中の版をpreviousへ、previousをprevious2へ移し、
  それまでのprevious2だけを削除します。削除された最古世代はこの仕組みからは
  復元できません。長期保存したい版はこの3フォルダー以外へ別途コピーしてください。
